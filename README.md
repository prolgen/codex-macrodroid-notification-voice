# MacroDroid Notification Voice — v1.0.0

Плагин Codex для повторяемой настройки озвучивания уведомлений на Android через MacroDroid.
Задайте приложения, ключевые слова и исключения обычным текстом. Codex подготовит макрос,
поможет подключить телефон, применить настройки и проверить результат.

**Требуется локальный Codex на Windows, Android с MacroDroid и Python 3.11+.**
Для управления телефоном и передачи файлов используется Android SDK Platform Tools (ADB).
После настройки компьютер для работы макроса не нужен. Веб-чат без локальных инструментов
не получает доступ к телефону от одной установки плагина.

## Установка из репозитория

[Пошаговая инструкция для нового пользователя](FRIEND_GUIDE.md), включая готовый запрос для Codex.

Установка из `prolgen/codex-macrodroid-notification-voice`:

```powershell
codex plugin marketplace add prolgen/codex-macrodroid-notification-voice --ref v1.0.0
codex plugin add macrodroid-notification-voice@notification-voice
```

Первая команда скачивает каталог плагина с зафиксированной версией, вторая устанавливает
плагин в Codex. Файлы телефона эти команды не меняют. Начните новый чат после установки.
Если в вашей версии Codex нет команды `plugin add`, откройте каталог плагинов в приложении,
выберите источник **Notification Voice** и установите **MacroDroid Notification Voice**.

Для локальной проверки уже скачанного репозитория:

```powershell
codex plugin marketplace add .
codex plugin add macrodroid-notification-voice@notification-voice
```

Не добавляйте локальный и удалённый источник с одинаковым именем одновременно.
Версии Codex различаются; сначала можно проверить `codex plugin --help`.

## Первый запрос

> Используй $macrodroid-notification-voice. Настрой на моём телефоне озвучивание
> уведомлений Telegram со словами «доставка» или «курьер», кроме уведомлений
> со словом «реклама». Читай текст один раз, без дополнительного сигнала.

Другой пример:

> Настрой Telegram и MAX. В уведомлении должны одновременно быть «офис» или «склад»
> и «доставка» или «курьер». Слово «отмена» запрещает новый запуск.
> Произнеси «Пришла доставка», затем включи сигнал на 30 секунд с кнопкой остановки.

При первом подключении владелец сам подтверждает отладку и необходимые Android-разрешения.
При нескольких телефонах нужно выбрать конкретный. Плагин не угадывает устройство по старому адресу.

## Что делает v1

- Выбор одного или нескольких приложений по Android package ID.
- Любые слова внутри группы; обязательное совпадение всех групп; слова-исключения.
- Буквальный поиск, целые слова/подстроки, учёт/игнорирование регистра.
- Чтение тела уведомления или фиксированной фразы; голос/скорость в настройках.
- Необязательный периодический звук 1–600 секунд, уведомление и кнопка остановки.
- Подготовка выключенного макроса, контрольные суммы файлов, проверка фактического экспорта.
- Диагностика ADB, версий, доступа к уведомлениям и фоновой работы.
- Перенос на другой телефон без изменения исходного кода.

Внутри плагина: навык, обезличенный шаблон `.macro`, примеры правил и локальный Python-инструмент.
Дополнительные Python-пакеты, сервер, n8n, API-ключи и облачная обработка уведомлений не нужны.
MacroDroid и голосовой движок устанавливаются отдельно; их лицензии и доступность функций
определяются самими приложениями.

## Честные ограничения

Шаблон основан на экспорте MacroDroid **5.67.8**. Это не официальный стабильный API.
Для другой версии обязателен пробный импорт выключенного макроса и проверка экспорта.
Импорт и системный выбор WAV выполняются через интерфейс приложения; плагин не обещает
полностью безучастную установку. Готовый файл не означает, что правило проверено на телефоне.

В v1 нет отдельных условий для заголовка/тела, расписания, автоматического склонения слов,
привязки к скрытому идентификатору чата, отмены текущего звука словом-исключением или
гарантированной очереди сигналов. Эти запросы требуют явной доработки.
Полный текст сообщения может отсутствовать в уведомлении. Серия уведомлений может давать
наложение звука. Кнопка Стоп останавливает воспроизведение, не гарантируя отмену очереди речи.
Макросы со звуком могут влиять на другое воспроизведение MacroDroid.

Python-тесты проверяют правила и файлы, но не доказывают доставку уведомлений, слышимость
или длительную работу Android в фоне. Настройка не заменяет официальное экстренное оповещение.

## Приватность и обновление

Реальные профили, экспорт телефона, коды сопряжения и журналы уведомлений не публикуются.
Храните их в отдельной личной папке; локальные каталоги `local`, `dist`, `backups`, `logs`
исключены из Git. Для приватности выберите установленный автономный голос Android.

Обновляйте плагин на конкретную опубликованную версию после просмотра изменений.
Обновление плагина само по себе не меняет макросы на телефоне: повторно запустите навык
для выбранного правила и сохраните резервную копию перед его применением.
Отключение правила: MacroDroid → Макросы → `NV_<идентификатор>` → выключить.

## Разработка и проверки

В PowerShell из корня репозитория, с установленным Python:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe scripts\validate_package.py
```

Зависимости — только стандартная библиотека. Команды инструмента: `doctor`, `test`, `build`,
`push`, `verify-export`; подробные аргументы доступны через `--help`.
Личные данные вводите в приватный рабочий каталог, а не в исходники плагина.
