# Инструкция для друга — v1.0

Этот плагин помогает Codex настроить телефон Android: читать уведомления выбранных приложений,
если в них есть нужные слова, и при желании включать дополнительный сигнал.
После настройки телефон работает самостоятельно, компьютер можно выключить.

## 1. Что потребуется

- Компьютер Windows с локальным приложением Codex и доступом к выполнению команд.
- Android-телефон с установленным MacroDroid и приложение, уведомления которого нужно читать.
- USB-кабель с передачей данных. Беспроводное подключение также возможно, но USB проще для первого раза.
- Python 3.11+ и Android SDK Platform Tools (ADB). Если их нет, попросите Codex помочь установить из официальных источников.

Обычного чата на сайте ChatGPT недостаточно для подключения телефона. Подписка и ограничения
MacroDroid определяются самим приложением; плагин не покупает платные функции.

## 2. Установить плагин через Codex

Откройте локальный Codex, выберите отдельную рабочую папку и вставьте этот запрос целиком:

```text
Установи плагин MacroDroid Notification Voice из публичного репозитория
https://github.com/prolgen/codex-macrodroid-notification-voice
Используй опубликованную версию v1.0.0 и штатные команды Codex:
codex plugin marketplace add prolgen/codex-macrodroid-notification-voice --ref v1.0.0
codex plugin add macrodroid-notification-voice@notification-voice
Сначала проверь доступность этих команд и существующий источник notification-voice.
Не заменяй другой источник с таким именем без объяснения.
Если команда codex не найдена, помоги найти установленный Codex CLI;
не скачивай неизвестные установщики и не меняй настройки телефона на этом этапе.
Проверь результат установки и объясни, как начать новый чат с навыком.
```

Вместо запроса можно самостоятельно выполнить две команды установки в PowerShell.
Первая скачивает каталог плагина из репозитория GitHub с конкретной версией;
вторая устанавливает его в Codex. Они меняют только локальную установку Codex,
не публикуют ваши данные и не меняют телефон.

Если текущая версия Codex не поддерживает `plugin add`, после добавления каталога откройте
в приложении каталог плагинов, источник **Notification Voice**, плагин **MacroDroid Notification Voice**.
Если источник не появился — перезапустите Codex. После установки начните **новый чат**.

## 3. Сформулировать правило

Скопируйте пример в новый чат, заменив приложения и слова своими:

```text
Используй $macrodroid-notification-voice.
Настрой на моём Android через MacroDroid такое правило:
- Приложение: Telegram.
- В уведомлении должно быть хотя бы одно слово: доставка, курьер.
- Если есть слово реклама, ничего не произносить.
- Искать целые слова без учёта регистра.
- Читать тело уведомления на русском один раз.
- Дополнительный сигнал не нужен.
Сохрани другие мои макросы. Перед изменениями сделай резервную копию.
Проверь установленное правило и проведи меня через проверку реального уведомления.
```

Более сложный пример:

```text
Используй $macrodroid-notification-voice.
Источники: Telegram и MAX.
В одном уведомлении нужны обе группы:
1) офис или склад;
2) доставка или курьер.
Слово отмена запрещает новый запуск.
Произноси «Пришла доставка», затем включай сигнал на 30 секунд с кнопкой Стоп.
```

«Офис или склад» означает любое слово внутри группы. Две группы означают, что должна совпасть
каждая группа. Словоформы перечисляются явно: «склад», «склада», «складе».
Исключение запрещает новый запуск, но не останавливает уже звучащий сигнал.

## 4. Подключить телефон и применить правило

Codex проверит инструменты и объяснит действия для вашей модели телефона. Обычно потребуется:

1. Подключить телефон по USB, разблокировать его и включить USB-отладку в параметрах разработчика.
   Подтвердить на телефоне разрешение отладки с этого компьютера. Не подтверждайте незнакомые компьютеры.
2. Если устройств несколько — явно выбрать нужное.
3. Разрешить MacroDroid доступ к уведомлениям и проверить уведомления исходного приложения/чата.
4. Сохранить резервную копию существующих макросов, импортировать подготовленный одиночный макрос.
   Не выбирать замену всего набора макросов без понимания последствий.
5. Если используется сигнал — выбрать переданный WAV через системный выбор файла внутри действия MacroDroid.
6. Проверить голос, громкость, разрешения и фоновую работу. Для приватности выбрать автономный голос.
7. Экспортировать установленный макрос для сравнения с заданными условиями, затем включить правило.

Часть системных подтверждений выполняется вручную на телефоне. Плагин не обходится без них.
Тексты ваших реальных уведомлений и коды сопряжения не нужно отправлять в чат или выкладывать в репозиторий.

## 5. Проверить результат

- Получите настоящее входящее уведомление с нужными словами: телефон должен произнести ожидаемый текст.
- Проверьте уведомление со словом-исключением и без нужных слов: озвучивания быть не должно.
- Проверьте каждое выбранное приложение отдельно.
- Если есть сигнал, проверьте его длительность и кнопку/уведомление Стоп.
- Повторите проверку с заблокированным экраном, после перезагрузки и без подключённого компьютера.

Ручной запуск макроса проверяет звук, но не проверяет поступление уведомлений.
Попросите Codex отдельно отметить, что проверено, а что осталось непроверенным.

## 6. Изменить правило или отключить

Для изменения снова вызовите навык и укажите существующее правило, например:

> Используй $macrodroid-notification-voice. В существующем правиле доставки добавь слово «посылка».
> Обнови правило без создания дубликата, сохрани резервную копию и проверь результат.

Отключение: MacroDroid → Макросы → правило с именем `NV_…` → выключить.
USB/беспроводную отладку после настройки можно выключить: для озвучивания она не требуется.

## Что учитывать

Выпуск v1.0.0 проверен автоматическими тестами и установкой в Codex. Новый генератор ещё
не прошёл испытание на физическом телефоне; поэтому проверка вашего устройства обязательна.
Шаблон основан на MacroDroid 5.67.8; другую версию Codex должен проверить через импорт/экспорт.
Android может ограничивать фон, исходное приложение — скрывать или обрезать текст уведомления.
При серии уведомлений звуки могут накладываться. Стоп останавливает сигнал, но не гарантирует отмену очереди речи.
Не используйте настройку как единственный канал экстренного оповещения.

Исходники и подробности: [репозиторий](https://github.com/prolgen/codex-macrodroid-notification-voice),
[результаты проверки](VALIDATION.md). Плагин не является официальным продуктом MacroDroid.
