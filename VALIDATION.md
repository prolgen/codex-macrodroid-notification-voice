# Проверка v1.0.0 — 12.11.2026

## Подтверждено локально

- 16 автоматических тестов пройдены на Windows с Python 3.13 и 3.14.
- Проверены группы слов, исключения, регистр, границы слов, многострочный текст и буквальные спецсимволы.
- Проверены ограничения профиля, стабильные идентификаторы, выключенное состояние нового макроса.
- Проверены длительность сгенерированного WAV, контрольные суммы и отказ от перезаписи существующего результата.
- Проверены выявление изменённых условий/действий, дубликатов, недостающего URI, вложенного действия Стоп и испорченного экспорта.
- Проверены отсутствие неявного выбора телефона, ограничения путей и передача с имитатором ADB.
- Проверены реальный запуск команд test/build/verify-export на синтетическом примере и обработка ошибки отсутствующего файла.
- Валидатор навыков OpenAI `quick_validate.py`: успешно. Для него в окружение разработки установлен PyYAML 6.0.3; самому плагину он не нужен.
- Проверка структуры плагина, ссылок и известных признаков личных данных: успешно.
- Codex CLI принял каталог и установил плагин версии 1.0.0 в отдельном тестовом профиле. Основной профиль пользователя не изменён.
- Независимый обзор кода: два замечания исправлены, добавлены проверки регрессий; повторный обзор и все 16 тестов успешны.

## Не подтверждено

- Импорт нового сгенерированного макроса на физическом телефоне.
- Совместимость нового Java-регулярного выражения с конкретной установленной версией MacroDroid.
- Слышимость голоса/сигнала, доступ к WAV, реальное входящее уведомление, остановка, перезагрузка и длительный фон.
- Загрузка через опубликованный GitHub-репозиторий и запуск GitHub Actions до публикации.

Исторические шаблоны были проверены на телефонах, но их результаты не перенесены автоматически на новый генератор.
Надёжность доставки уведомлений не измерена. Успешная установка плагина подтверждает его упаковку,
а не работу правила Android. Процедура навыка требует отдельной приёмки каждого телефона.
